# Scorsaire Lecteur

Lecteur de **recueils** (setlists) Scorsaire, installable sur une tablette ou une liseuse et utilisable **hors ligne**.

- Ouvrez l'application : <https://jelhoste.github.io/scorsaire-lecteur/>
- Installez-la depuis le navigateur (« Ajouter à l'écran d'accueil » / « Installer »).
- Ouvrez un recueil `.scorsaire-recueil` (ou une ou plusieurs œuvres `.scorsaire`) depuis le menu, ou par adresse :
  `https://jelhoste.github.io/scorsaire-lecteur/?file=exemples/essai.scorsaire-recueil`
- Exemple avec **paroles et accords** (bouton « Paroles » du menu) :
  `https://jelhoste.github.io/scorsaire-lecteur/?file=exemples/paroles.scorsaire-recueil`
- Appui dans les trois quarts droits de l'écran : page suivante. Quart gauche : page précédente. Balayage depuis le haut : menu.
- Rien n'est envoyé nulle part : le recueil et vos réglages restent sur l'appareil.

Ce dépôt ne contient que l'application construite (publiée par `npm run publier-lecteur` depuis le dépôt de Scorsaire) et le dossier `exemples/`.
